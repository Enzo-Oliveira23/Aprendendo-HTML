- REDE INTERNA VS REDE EXTERNA 

todo serviço construido na estrutura da internet é uma programação web

ip - Numero "cep de uma rua", local onde o dispositivo está
dns - O DNS converte os nomes de domínio em endereços de IP para que os navegadores possam carregar os recursos da internet.
dominio - google.com 

FRONT END VS BACK END = cliente x servidor

tecnologias Front end

- HTML - linguagem de marcação para estruturar textos, criar links, imagens etc
- CSS - linguagem para estilizar o HTML
- JAVASCRIPT - linguagem de programação que funciona no navegador 

tecnologias back end

- NODEJS - rodar o javascript no computador
- SQL - banco de dados para proteger os dados do programa
